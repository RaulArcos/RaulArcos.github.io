02 — HOW TO USE IT3 STEPS
  1. 01

    Download and unzip

    Grab the zip from GitHub and extract it wherever you like. There's nothing to install.

  2. 02

    Open it and pick

    Run RAH_Telemetry_Overlay.exe, choose an overlay and flip its switch. It shows up over iRacing. Hit Position to drag it where you want it.

  3. 03

    Streaming? Add it to OBS

    Copy the overlay's OBS link from the app and add it as a Browser Source, using the width and height the app gives you. Done.

MAKE IT YOURS

Each overlay has its own settings in the app, with a live preview while you play with them. OBS picks up the changes within a couple of seconds, no need to refresh the source.

  • ORIGINAL OR GLASS
  • OPACITY
  • BACKGROUND OPACITY
  • SIZE 50–200%
  • ACCENT COLOUR
  • HIDE TITLE / FOOTER
  • HIDE COLUMNS AND PARTS
03 — GOOD TO KNOW
Is it really free?

Yes. No account, no subscription, no ads. The code is on GitHub if you want to check it or change something.

Windows says it "protected my PC"

The app isn't code-signed (those certificates cost money every year), so SmartScreen can complain the first time you open it. Click "More info" and then "Run anyway".

Does it touch iRacing or my account?

No. It only reads the telemetry iRacing already shares with apps on your PC. It never sends anything to the sim, and the overlays are served from your own computer.

My iRating doesn't show in AI races

iRacing doesn't share it in AI sessions. Once you've done an online session with the app open, it remembers your last iRating and licence and shows those instead.

Will it hurt my FPS?

They're small web pages updating about 30 times a second, so the impact is tiny. If you're tight on performance, only switch on the ones you actually look at.

Something's broken or I have an idea

Open an issue on GitHub or tell me on Twitch. I race with these myself, so there's a good chance I'll want it too.
